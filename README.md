# dann.com.br

Source of [dann.com.br](https://dann.com.br/), the blog of `intrd`: CTF write-ups,
security research notes and side projects. Migrated from Ghost to [Hugo](https://gohugo.io).

## Build

```sh
hugo server        # local preview at http://localhost:1313/
hugo               # static output in public/
```

Pushes to `main` are built and deployed to GitHub Pages by
`.github/workflows/pages.yml`.
